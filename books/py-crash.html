Python Crash Course

Eric Matthes

Overview

I think it has been at least 7 years since I read this book. It is probably the most recommended starting point when it comes to learning Python. Matthes covers basic topics like lists, statements, dictionaries, input and loops, functions, classes, files, and testing. Learning is done through 3 projects: a game, data visualisation, and a web app through Django. Each chapter covers some exercises at the end to make sure you understand what you have just learned. I don't think there is much more to say than it being a really good introductory book.

Key Takeaways

The projects at the end introducing Pygame, APIs, and Django.

Who Should Read This

If you have no idea how Python works, this is a good starting point.

Rating

4 out of 5.
