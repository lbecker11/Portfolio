The C Programming Language

Brian Kernighan & Dennis Ritchie

Overview

The C Programming Language is probably one of the most read programming books out there. Most of my programming was always done in Python. I watched a few videos on C and did some online courses just out of curiosity. Once I decided to commit to learning the basics of the language and read this book, everything started to make so much more sense to me. Because C is such a low-level language, you start to understand all the abstraction done by other languages and you understand data structures and algorithms from the ground up. I think this is an essential part of any programmer's knowledge. Even if you never touch C again, the low-level foundations will help you understand most concepts much faster. The whole idea behind linked lists, hash tables, hashing in general, memory management, and pointers makes everything so much clearer. Pairing this with Algorithmic Thinking by Daniel Zingaro makes it click even more.

Key Takeaways

Memory management, linked lists, hashing.

Who Should Read This

Everyone who is interested in programming and, like me, wants to know the why and how behind concepts.

Rating

5 out of 5, essential read for anyone.
