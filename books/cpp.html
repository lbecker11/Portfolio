The C++ Programming Language

Bjarne Stroustrup

Overview

I wanted to get a better overview of how C++ works and how to write it, so what better book to read than one by the creator himself. The C++ Programming Language is separated into four parts: introduction material, basic facilities, abstraction mechanisms, and the standard library.

The introduction acts as a high-level overview of how C++ works and what was new in C++11. The basic facilities part covers the standard syntax. This is very similar to C — types, pointers, and arrays — along with references, which are C++ specific. This is followed by structures, which are later essentially modified to create classes, unions, and enumerations. The section also covers statements, expressions, and exception handling, which is another feature specific to C++ and absent in C. One thing I also like about C++ is that you can create namespaces to better organise code and avoid naming conflicts.

The third part covers abstraction, which is the main reason C++ was created. Here you learn how to create classes — data structures with operations — and advance from built-in types to user-defined types. Classes make use of the RAII concept, meaning "resource acquisition is initialization". Instead of using old patterns like malloc and free, resources are built into the type itself. This is why containers from the standard library are so effective: they are efficient resource handles. Abstraction also extends to templates, which enable generic programming. Rather than defining exact types as in C, you can abstract over what types are valid and use predicates to enforce that arguments satisfy the operation's requirements. Through this, you can dive deeper into specialisation and create powerful custom user-defined types.

The last part covers the C++ standard library, with high-level concepts like containers, algorithms, and iterators, as well as memory, I/O streams, concurrency, and threads and tasks.

Key Takeaways

There are so many key concepts here that it is hard to name them all. The book not only teaches how C++ works but also important computer science concepts that translate well into other languages. For me, efficient class design through abstract classes and polymorphism was one example — something I was able to apply in Python fairly quickly as well. The sections on concurrency and threads also gave me a much better understanding of how things like IPC can be built in C++.

Who Should Read This

Anyone who wants to understand how C++ works under the hood. Ideally take an introductory course first so that the concepts click faster when you encounter them in the book.

Rating

4 out of 5. I still found myself looking up many concepts, as they were not described in enough detail for me to understand them directly from the book.
