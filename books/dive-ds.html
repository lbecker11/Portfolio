Dive Into Data Science

Bradford Tuckfield

Overview

You can never go wrong when reading books from NoStarch, and this book proves this again. In this book we learn a very basic introduction to data science and the most used Python libraries that come with it. It does not go into great detail, but it does enough to spark a major interested in wanting to learn more.

Key Takeaways

I think the chapters on supervised and unsupervised learning did a great job at introducing the topics and how to work them in Python.

Who Should Read This

If you need a quick uncomplicated introduction that does not go into too much math details to data science, this is the one.

Rating

5 out of 5, because this book started my interest in data science and math.
