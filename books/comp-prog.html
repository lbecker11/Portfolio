Competitive Programming

Antti Laaksonen

Overview

After having read Algorithmic Thinking I wanted some more insight on competitive programming because it is a fun exercise. A book that was recommended to me was Competitive Programmer's Handbook. Because this book is a handbook it covers most topics at a very high level. I think the depth is just right, and if you require more detail you can always refer to the main book or look up the technique. This book covers a lot of basics like time complexity, sorting, and data structures. It also covers a lot of graph algorithms like DFS and BFS, and algorithms derived from them like Bellman-Ford, which can be used to perform arbitrage calculations. Then there is some information on more complex topics like number theory, probability, game theory, and geometry. It is dense knowledge and does require time, patience, and practice to get the hang of it. The main idea to remember is that these algorithms are not just fun techniques for LeetCode or Codeforces but can be applied in many domains, like finance and trading.

Key Takeaways

There are a lot of different graph algorithms. Number theory has a lot of uses and is a topic I would want to do more reading on.

Who Should Read This

If you are interested in learning algorithms for both competition and your own projects, this is a good starting point to specialise from.

Rating

4 out of 5. Sometimes the descriptions are lacking some needed detail.
