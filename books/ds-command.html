Data Science at the Command Line

Jeroen Janssens

Overview

Data Science at the Command Line was an interesting read. I must admit I don't think I have used a lot of the information from this book so far, but it was a good introduction to the terminal and Docker. It gives an alternative to the usual Python Pandas or Polars data cleaning and pipeline that I am so familiar with. Instead, the author performs these operations in the command line. I think it is an interesting concept to build your own command line tools for increased productivity, especially now with MCP around. These custom CLI tools can definitely be passed on to agents.

Key Takeaways

Docker and basic command line instructions.

Who Should Read This

I am actually not sure, because it is definitely not an essential read but more of a fun side step from the main data science path.

Rating

3 out of 5. It was well written and explained but for me personally I did not see an exact use for it.
