Software Engineering for Data Scientists

Catherine Nelson

Overview

This is another one I would say is essential without covering statistics, maths, or ML. An issue with a lot of data analysts and data scientists is Jupyter Notebooks and the problems they introduce. Software Engineering for Data Scientists goes into great detail as to why people in analyst positions should think like engineers. How to use APIs, why good documentation is essential, why knowing data structures and algorithms is important, how to deploy models, using Git and virtual environments, and introducing testing like pre-commit hooks. This becomes especially important when your ML models need to be hooked up into larger systems. For example, if you have a trading system with an interface running in C++ that dispatches jobs, your model running in Python needs to be able to receive those instructions, act on them, and send the results back. This does not work in something like a notebook. This is why the general software engineering mindset is important in this field too.

Key Takeaways

Testing, logging, APIs, deployment.

Who Should Read This

Any data analyst or data scientist who thinks "why should I do this, I am not a software engineer".

Rating

5 out of 5, essential concepts that need to be adopted.
