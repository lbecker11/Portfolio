Job Messenger

2026
  • Automation
  • Python
  • Python
  • Playwright
  • Requests
  • GitHub Actions

My girlfriend is applying to physio jobs and it is hard to constantly check the website or wait for the odd email notification of a new posting. I had the idea to make use of the WhatsApp API and GitHub Actions to scrape the postings, take a snapshot, and check if anything has changed. This way she can receive a WhatsApp notification as soon as a new job comes out.

Architecture

Meta & WhatsApp

To communicate through the WhatsApp API you need to set up a Meta Business account and create an app in the developer dashboard. This is straightforward following the online instructions. Because notifications only go out to one person, the free sandbox environment was all that was needed.

Scraping

Playwright was the right module here as it emulates a headless browser, making it easier to pull information from JavaScript-rendered pages. Because the target website is pure HTML, getting all the needed fields was simple to implement. The results are stored in a JSON file after each run.

Comparing

Each time the website is scraped, the JSON content is hashed. This allows for a quick comparison to detect whether anything has changed — a new posting or a removal. Only when the hash values differ does the actual comparison run. Comparing is then just a matter of diffing the old and new links and building a WhatsApp message from the result.

Requirements

pip install requests python-dotenv playwright
playwright install chromium
